# PW Loja Online

Perfis: `admin@teste.com / 123456` e `usuario@teste.com / 123456`.

Usuário: catálogo, carrinho, checkout e próprios pedidos. ADMIN: todos os pedidos, alteração de status, CRUD de produtos e usuários. O checkout valida e baixa estoque em transação.

Backend: `mvnw.cmd spring-boot:run`. Frontend: `npm install` e `npm run dev`. Swagger em `http://localhost:8080/swagger-ui.html`.
